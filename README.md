# PyQt HiCode Shop

這是一個基於 Python 與 PyQt5 打造的現代化桌面電子商務應用程式，並採用了 SQLite Cloud 雲端資料庫來實現多客戶端資料同步。

## ✨ 功能特色

- **完善的會員與權限系統**
  - 具備登入機制與註冊功能。
  - 支援多種權限角色：`admin` (管理員)、`seller` (賣家) 與 `user` (一般買家)。
  - 安全的 SHA-256 密碼雜湊加密機制。

- **購物體驗 (買家端)**
  - **商品商城**：瀏覽所有上架商品，並將商品加入購物車。
  - **購物車系統**：動態調整購買數量 (自動計算金額)、確認餘額並進行結帳防呆。
  - **訂單紀錄**：查看購買明細與狀態。支援向賣家「申請取消」訂單，並可檢視取消進度或被駁回的緣由。
  - **會員錢包**：查看錢包餘額，並可透過兌換碼機制進行安全儲值。

- **賣家中心 (賣家端)**
  - **商品管理**：填寫商品資訊以快速上架商品，或將舊有商品下架刪除。
  - **訂單管理**：追蹤客戶訂單，將商品標記為「已完成」。
  - **退款與駁回機制**：針對買家提出的取消申請，賣家可以選擇「同意取消」(系統將自動退款並返還庫存) 或附上緣由「駁回申請」。

- **系統管理後台 (管理員專屬)**
  - **會員管理**：查詢與管理全站會員清單。
  - **兌換碼系統**：發行自訂面額與使用次數上限的錢包兌換碼。

## 🛠️ 技術堆疊

- **前端介面 (GUI)**: Python 3, PyQt5
- **雲端資料庫**: SQLite Cloud (`sqlitecloud`)
- **環境管理**: `python-dotenv` (用於隱藏 API Keys 與敏感資訊)
- **佈局特色**: 採用 `QVBoxLayout`、`QHBoxLayout` 等自適應排版，以及自動拉伸調節寬度的表格設計 (`QTableWidget`)。

## 🚀 安裝與運行指南

### 1. 環境準備
請確保您的電腦已安裝 **Python 3.8+**。

### 2. 安裝套件依賴
請在終端機 (Terminal) 中切換至專案目錄，並執行以下指令來安裝所需的第三方套件：

```bash
pip install -r requirements.txt
```

### 3. 設定環境變數 (.env)
為了保護您的資料庫連線資訊，專案根目錄必須放置一個 `.env` 檔案，內容格式如下：

```env
SQLITE_CLOUD_URL=sqlitecloud://your-project-id.sqlite.cloud:8860?apikey=your_api_key
```
*(請將上述網址替換為您在 SQLite Cloud 取得的真實連線字串)*

### 4. 啟動應用程式
設定完成後，您可以直接執行主程式啟動應用程式：

```bash
python main.py
```

> **💡 資料庫自動升級機制 (Auto Migration)**
> 每次執行 `main.py` 時，系統會自動呼叫 `db_cloud.py` 中的 `ensure_schema_updated()` 函式。
> 該函式會檢查雲端資料庫是否具備最新的表格與欄位 (如 `rejection_reason`, `seller_id` 等)，並自動補齊缺失的架構，確保專案正常運行。

## 📂 專案架構說明

- `main.py`: 應用程式進入點，負責啟動程式、檢查資料庫與處理登入/登出生命週期。
- `db_cloud.py`: 負責與 SQLite Cloud 進行連線、密碼雜湊處理與資料庫自動升級維護。
- `gui/`
  - `main_window.py`: 商城主視窗框架與頁籤導航列。
  - `login_window.py`: 登入與註冊畫面介面邏輯。
  - `admin_window.py`: 管理員後台彈出視窗。
  - `tab_*.py`: 負責實作主視窗內的各項功能頁籤 (商城、購物車、訂單、錢包、賣家中心)。
- `requirements.txt`: 專案相依性套件清單。
- `.env` (不包含在版控中): 儲存資料庫連線金鑰。
